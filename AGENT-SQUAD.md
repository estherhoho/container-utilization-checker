## Multica Squad

### 1. Product Manager Agent

- `PRODUCT-SPEC.md`
- MVP scope
- success criteria
- monetization path
- launch status recommendation

### 2. Supply Chain SME Agent

Outputs:

- Container and CBM assumptions
- importer / forwarder / warehouse use cases
- data requirements
- edge cases
- formula validation checklist

### 3. UX Designer Agent

Outputs:

- user flow
- first-screen layout
- input form structure
- result page structure
- mobile review notes

### 4. Developer Agent

Outputs:

- static HTML/CSS/JS MVP
- deterministic calculation functions
- validation rules
- sample CSV support if included
- Vercel preview

### 5. QA Reviewer Agent

Outputs:

- `REVIEW-GATE.md`
- P0/P1/P2/P3 findings
- mobile + desktop test
- placeholder check
- formula sanity checks

### 6. Launch / Marketing Agent

Outputs:

- website tool card copy
- SEO title / description
- LinkedIn post draft
- 小红书 post draft
- review summary for Esther
